# IRNIC 3-Character Domain Audit & Live Index

Comprehensive investigation and live WHOIS audit of the 3-character `.ir` domain space conducted directly against the IRNIC registry.

## Key Findings
- **3-Letter Domains (`LLL.ir`):** **0 Free.** 100% of all 17,576 combinations (`aaa.ir` to `zzz.ir`) are registered.
- **3-Digit Domains (`NNN.ir`):** **0 Free.** 100% of all 1,000 combinations (`000.ir` to `999.ir`) are registered.
- **3-Character Mixed Domains (`LLN` / `LNL` / `NLL`):** Available with high-value brandable, leet-speak, and dev names.
